Mods & side projects

Order of Aurelia

An extension mod for Unciv - Gods & Kings, built around King Lucian and a civilization focused on social cohesion, scientific development, institutions, and defensive military organization. View repository.

NMod

An Unciv mod adding nations, policy trees, buildings, and specialized units, including Agent spy units. It keeps the base ruleset intact rather than replacing it, preserving the espionage mechanics the mod is built around. View repository.

My Notes

A lightweight notes web app deployed on Cloudflare Workers, with keyboard-driven search and navigation for browsing notes. View repository.
